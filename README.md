### 🛡️ Featured Engineering & Mobility Projects

#### 🚗 [Vehicle BLE Companion App & HUD Scanner](https://github.com/fahedbelhiba/vehicle-ble-companion)
*Native Android Kotlin • BLE GATT • Coroutines • StateFlow • MVVM*
- Real-time vehicle telemetry dashboard and remote control via Bluetooth Low Energy GATT client.
- Calibrated RSSI proximity auto-unlock zone (`-65 dBm`), live battery SoC% / range monitoring, and cabin pre-conditioning commands.

#### 📡 [In-Vehicle Wi-Fi Direct P2P Link](https://github.com/fahedbelhiba/vehicle-wifi-direct-link)
*Android SDK • WifiP2pManager • TCP Sockets • Kotlin*
- High-speed peer-to-peer data channel between smartphone and in-vehicle head unit for rapid diagnostic data exchange without cellular network.
- Autonomous P2P group negotiation and length-prefix framed TCP diagnostic protocol with auto-reconnection.

#### 🩺 [ESP32 Pulse Sensor & Android Health Monitor](https://github.com/fahedbelhiba/android-health-monitor)
*ESP32 (C++/FreeRTOS) • BLE GATT Heart Rate (0x180D) • Android Kotlin • Room DB*
- ESP32 firmware reading MAX30102 optical sensor with Pan-Tompkins algorithm advertising BPM and SpO2 via standard BLE GATT Heart Rate Service.
- Companion Android app with animated gauges, live MPAndroidChart telemetry sparkline, and Room DB session history.

#### 🚘 [Vehicle OBD-II & CAN Bus Dashboard](https://github.com/fahedbelhiba/vehicle-can-dashboard)
*Android Kotlin • Bluetooth RFCOMM • ELM327 • OBD-II PIDs*
- Real-time vehicular diagnostic cluster via Bluetooth ELM327 adapter: RPM arc gauge, speedometer needle, coolant temperature, and DTC fault code scanning/clearing.

#### 🚙 [Driver Profile & Cloud Sync Service](https://github.com/fahedbelhiba/driver-id-profile-sync)
*Kotlin • Room DB • WorkManager • GCP Firestore • Offline-First*
- Autonomous in-cabin driver identification service with zero-latency Room local cache and asynchronous background sync to cloud NoSQL.

#### 🌐 [Smart Parking IoT Sensor](https://github.com/fahedbelhiba/smart-parking-iot)
*ESP32 • HC-SR04 • MQTT • FreeRTOS • Python SQLite*
- ESP32 ultrasonic parking space monitor detecting spot occupancy with 3-reading debouncing and publishing retained MQTT QoS 1 telemetry over Wi-Fi.

#### ⚡ [Java Spring Boot Carpooling Platform](https://github.com/fahedbelhiba/carpooling-platform-java)
*Java 17 • Spring Boot • JPA/Hibernate • SQL ACID • JWT • Docker*
- Full-stack carpooling platform with transactional trip booking, optimistic locking against double-booking, JWT authentication, and Docker Compose orchestration.

#### 📊 [Eco-Driving Score App](https://github.com/fahedbelhiba/eco-driving-score)
*Android Kotlin • SensorManager • Accelerometer • GPS • Room DB*
- Real-time driving behavior telemetry calculating G-force events (braking, acceleration, cornering), computing trip eco-scores and estimated CO2 reduction.
